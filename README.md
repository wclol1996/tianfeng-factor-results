本次交付及后续更新只计算因子值，不计算IC。

固定范围：最早校对151项＋后来修正接纳27项＋无天风对照样本逻辑接纳69项。历史31项中的OPR_Skew、con_np2opr_fy1、con_roe_fy1、sfli2及其他候选不纳入。

## 下载与读取

在[Releases](https://github.com/wclol1996/tianfeng-factor-results/releases)下载因子值分卷、说明文档、目录、校验清单及计算源码。下载全部10个 `factor-values-247-part-*.zip`，分别解压到同一目录，无需拼接ZIP。

文件结构：`values/因子ID/year=年份/values.parquet`，主要字段：`date, security_id, value`。

当前冻结快照包含3,914个年度分区，约17.7GB；存储2,657,670,463条记录，包含缺失值。整体日期2011-01-04至2026-09-08，各因子覆盖见目录。原频率定义为日频137项、月频110项；月频值的日度存储不代表每天重算公式。

## 计算与更新

沿用各因子已接纳的版本、参数和输入窗口，维持历史ST过滤和最新可得PIT。当前通用引擎不等同于所有历史独立修复版本，更新时须绑定相应版本；数据或版本门禁缺失应报告失败，不能替换公式强跑。Tushare原始行情、财报源数据、凭证及参考样本留在本地。

本地自动任务每日北京时间23:30检查并推进因子值更新，记录实际截止日和逐项状态，再发布成功结果。安排自动任务不代表已验证247项全量增量计算。

验收依据：严格数值通过152项，历史PIT差异接纳17项，用户近门槛统一规则接纳6项，无对照逻辑接纳69项，有参考未数值核验的逻辑接纳3项。保留各项原类别。

仓库旧IC展示文件属于之前未完成发布的历史版本，不作为本次247项因子值交付入口。
