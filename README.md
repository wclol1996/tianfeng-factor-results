# 天风因子日度统计结果

待发布网页文件；远端仓库当前仍为空，尚无可用在线地址。

本地打开index.html，选择日期窗口、预测期和因子范围。每月滚动窗口支持半年、1年、2年、5年回看。点击因子查看每日 IC / RankIC 曲线，可导出当前排序及当前因子日度统计。

范围：260项历史接纳因子；窗口为2010—2019、2013—2022，2010缺少候选及历史ST认证。收益使用后复权，按历史日期剔除ST/*ST，上市满365自然日。ICIR、RankICIR均为每日相关系数均值除以样本标准差，不年化。

此仓库仅含聚合统计结果及展示代码；不含股票级因子值、原始行情、参考库、凭证、本地路径或内部审计文件。日度展示序列保留7位小数，汇总CSV保留计算精度。
